# 0.2.1

## English

- Fix `NodeExecutionEnv.listDir()` failing an entire listing when a child disappears between `readdir` and `lstat`, such as a session `.jsonl.tmp` renamed during atomic publication. Skip only child `lstat` `ENOENT` errors; `readdir` errors (including missing directories), permission failures and other I/O errors still return errors. Listings are not atomic snapshots and can omit entries changed concurrently.
- Add a deterministic regression test that renames a real temporary file after directory enumeration, plus checks that directory and child I/O errors remain visible.
- Public APIs, JSONL session formats and the required Pi peer versions (`pi-ai`, `chord` and `pi-telemetry` 1.5.2) are unchanged. Existing sessions need no migration.

## 简体中文

- 修复 `NodeExecutionEnv.listDir()` 在 `readdir` 与 `lstat` 之间某个子项消失时导致整个列举失败的问题，例如会话原子发布时 `.jsonl.tmp` 被重命名。仅跳过子项 `lstat` 的 `ENOENT`；`readdir` 错误（包括目录不存在）、权限不足及其他 I/O 错误仍返回错误。列举不是原子快照，可能不包含并发变化的条目。
- 新增确定性回归测试：完成目录枚举后重命名真实临时文件，并检查目录和子项 I/O 错误仍正常返回。
- 公开 API、JSONL 会话格式和 Pi peer 版本要求（`pi-ai`、`chord`、`pi-telemetry` 1.5.2）保持不变，存量会话无需迁移。
