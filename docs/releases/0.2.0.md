# 0.2.0

## English

- Require the tested Pi peer set: `pi-ai`, `chord` and `pi-telemetry` exactly 1.5.2. Other versions, including newer patch releases, may cause npm `ERESOLVE`; upgrade to a harness release that validates those versions.
- Fix source and published declaration imports for Chord's `/context`, `/delta` and `/json` exports.
- Experimental Pico3: replace removed Chord v1 `ReplicatedState` types with a host-owned publication contract. Use `attachChordView(conversation, createConversationViewPublisher, context)` for atomic mutation, rollback and immutable snapshots. Custom publishers remain supported and must honor the documented transaction contract.
- A default-typed `PicoConversationService.view.value` can be undefined. Guard reads or keep the concrete publisher type through inference or a generic argument. Subscription methods belong to that concrete publisher.
- Add a self-building packed-consumer check to CI and release validation, including all public runtime exports and strict declaration checks with the documented GenAI type prerequisites.
- The main AgentHarness API and existing JSONL session format remain compatible; existing sessions require no migration.

## 简体中文

- Pi peer 精确要求 `pi-ai`、`chord` 和 `pi-telemetry` 1.5.2。其他版本（包括更新的补丁版本）可能触发 npm `ERESOLVE`；请升级到已验证对应 Pi 版本的 harness 版本。
- 修复源码和发布声明对 Chord `/context`、`/delta`、`/json` 导出的引用。
- 实验性 Pico3：以宿主发布契约替代已删除的 Chord v1 `ReplicatedState` 类型。可直接使用 `attachChordView(conversation, createConversationViewPublisher, context)` 获得原子修改、失败回滚与旧快照保留。仍支持自定义发布器，但需遵守事务契约。
- 默认类型的 `PicoConversationService.view.value` 可能为 undefined。读取前判空，或通过推断/泛型参数保留具体发布器类型；订阅方法属于该具体发布器。
- CI 和发布验证新增自动构建的打包消费检查，覆盖所有公开运行时入口，并在已说明的 GenAI 类型前提下严格检查声明。
- 主 AgentHarness API 和已有 JSONL 会话格式保持兼容，存量会话无需迁移。
